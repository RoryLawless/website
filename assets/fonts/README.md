# Newsreader web fonts

These six unmodified WOFF2 files are the Text optical size from the Newsreader
download supplied by Production Type.

`assets/custom.scss` loads Regular (400), Medium (500), Bold (700), and their
matching italics with `font-display: swap`. All supplied glyphs are available;
there is no Latin-1-only `unicode-range` restriction.
